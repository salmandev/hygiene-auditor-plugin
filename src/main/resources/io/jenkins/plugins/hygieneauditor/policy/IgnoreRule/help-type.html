Limit the rule to one kind of finding. A * matches any text. Leave empty to match every type.

Types:

  • job.stale, job.disabled, job.never_built
  • agent.offline
  • credential.unused
  • library.unreferenced, library.unused_class, library.unused_variable
  • plugin.needs_review, plugin.orphaned_data
Example: library.* exempts every shared-library finding.
