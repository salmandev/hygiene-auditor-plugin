Runs a Hygiene Auditor scan, waits for it to finish and returns the counts. The scan is read-only: nothing is changed or deleted. The build needs the Hygiene Auditor Scan permission.

The step returns a map with these keys:

  • scanId: the id of the scan
  • state: how the scan ended, for example COMPLETED or PARTIAL
  • open: open findings in the scanned categories that the build may see
  • high: how many of those have high severity
  • created: findings this scan found for the first time
  • resolved: findings this scan found to be resolved
Only counts are returned, never the findings themselves. 
def result = hygieneScan(categories: ['CREDENTIALS', 'JOBS'])
echo "${result.open} open, ${result.high} high severity"
